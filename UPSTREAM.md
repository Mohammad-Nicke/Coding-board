# Source

Keyboard engine and layouts derive from [Unexpected Keyboard](https://github.com/Julow/Unexpected-Keyboard), commit `38836e440d8ca779d572b52601c6b2ad10f3bb7f`, under GPL-3.0.

Coding-board adds the embedded view integration, text-input controller, clipboard history, layout switching, form controls, voice input, and adaptive tap learning. See `LICENSE` for the required attribution.

Adaptive touch learning also derives from GPL-3.0 source snapshot `ee4f83c3c41c43e09e27f4f81194647ba9990d79`; its package and host integration were adapted for this library.
